# 게임 기본 구조, 성장과 생활 배치

## 확정 — 핵심 콘셉트
- 포켓몬 수집·육성 + 길드 경영 + 방치형 RPG.
- 포켓몬은 던전 전투뿐 아니라 농사, 채집, 제작, 판매 등 생활 분야에 참여한다.
- 전투와 생활은 **동시 수행하지 못한다**. 포켓몬은 전투 또는 생활 쪽에 속한다.

## 확정 — 포켓몬 성장
- 전투 경험치와 생활 활동 경험치 모두 공통 레벨을 올린다.
- 생활 숙련도는 활동별로 따로 성장하고 배치 변경 시에도 유지된다.
- 포켓몬 개체마다 성격·개체값을 가진다.
- 진화 단계별로 생활 전문화가 달라진다. 진화 전 포켓몬에도 활용 가치가 있다.
- 생활 활동별 정확한 능력치 계산식·경험치 분배 방식은 미정이다.

## 확정 — 전투숙소와 생활숙소
- **3안(숙소 분리)** 채택. 전투숙소/생활숙소로 나눈다.
- 전투숙소 포켓몬은 지역 탐험에 보낼 수 있다. **탐험 중인 포켓몬은 방생 불가**.
- 생활숙소의 포켓몬 능력치를 각 생활 분야의 생산에 반영한다.
- 생활숙소 포켓몬 하나는 **단 하나의 생활 분야에만** 기여한다. 여러 분야에 중복 참여할 수 없다.
- 생활 분야 배치는 **수동 배치가 기본**이며 별도의 **자동 배치 버튼**이 있다.
- 자동 배치 버튼을 누르면 포켓몬별 생활 능력치를 비교해 **전체 생활 생산 효율의 합계가 최대**가 되도록 배정한다.
- 자동 배치는 상시 작동하지 않고 버튼을 누를 때만 실행한다. 이후 수동으로 바꿀 수 있다.
- 생활숙소에서 영입하거나 방생하면 관련 능력치와 생산 효율에 즉시 반영한다.
- 생활숙소 포켓몬은 활동별 직접 고정 투입형이 아니라 소속된 활동의 능력치에 기여하는 구조를 사용한다.

## 확정 — 탐험 지역 진행 방식
- **C안(혼합형)**: 주요 지역은 순차적으로 해금한다.
- 이미 해금한 지역은 언제든 다시 탐험할 수 있다.
- 구체적인 지역 해금 조건, 탐험 반복 보상, 전멸 페널티, 파티 인원 수는 미정이다.
- 전투·탐험이 게임의 **주요 콘텐츠 및 성장 목표**이며, 생활·경영은 이를 지원하는 보조 시스템이다.
- [참고 게임 분석](GUILD_MASTER_IDLE_DUNGEONS_ANALYSIS.md)은 원작 연구 자료이며 PokeTree 신규 확정 규칙으로 간주하지 않는다.

## 아직 미정
- 생활 분야별 배치 가능 인원 및 확장 방식 (**추후 결정 명시**).
- 자동 배치 최적화에 사용할 생산 효율 산식, 분야별 가중치, 동률 처리.
- 생활 숙련도 경험치 배분·성장 및 전투숙소의 탐험 미참여 포켓몬 처리.
- 시설별 생산법·채집·제작·판매의 상세 시스템.
