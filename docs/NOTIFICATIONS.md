# 주요 이벤트 알림 시스템 — 확정 및 미정

## 확정 규칙
- **주요 이벤트 발생 시 짧은 알림**을 표시한다. 예: 신규 지역 해금, 보스 처치, 포켓몬 부화.
- 일반 전투 결과·일반 아이템 획득은 기본 기록 대상에서 제외한다.
- 알림은 잠시 표시 후 자동으로 사라지며, **현재 화면을 유지**한다. 신규 지역이 해금되더라도 지역 목록으로 강제 이동하지 않는다.
- 주요 이벤트를 **별도 알림 기록**에 저장해 확인할 수 있다.
- 최근 **30개 기록**만 보관한다. 새 기록으로 30개를 초과하면 **가장 오래된 기록부터 자동 삭제**한다.
- 사용자는 **전체 삭제**할 수 있다. **개별 삭제는 지원하지 않는다**.
- 기록은 **게임 종료 시 모두 초기화**한다. 다음 실행은 빈 기록에서 시작한다. 지속 저장 데이터로 취급하지 않는다.
- 숨김 상태였던 신규 지역도 해금 순간 나타나고 알림을 표시한다.
- 탐험을 진행 중인 경우 알림으로 화면이 전환되거나 해당 탐험의 지역이 자동 변경되지 않는다.

## 미정 사항
- 알림이 실제로 화면에 표시되는 **시간**.
- **동시에 여러 알림**이 발생했을 때 표시 순서/배치/통합 방식(사용자가 추후 결정).
- 주요 이벤트의 완전한 범위와 알림 문구·화면 배치.
