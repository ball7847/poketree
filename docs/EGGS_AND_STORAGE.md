# 포켓몬 알·부화기·자동화·보관함

## 확정 — 알 획득 및 데이터
- 야생에서 포켓몬 알을 획득한다. 부화에는 공통 에너지를 사용한다. 주요 획득 경로는 특정 작물 수확.
- 알 등급은 7단계: **흔한 / 안흔한 / 특별한 / 희귀한 / 전설적인 / 신적인 / 초월적인**.
- 포켓몬 **종족마다 알 등급 하나가 고정**된다.
- 등급별로 부화 가능한 종족, 소모 에너지, 기본 부화 시간이 다르다. 높은 등급일수록 에너지 소모량과 기본 부화 시간이 증가한다.
- **알 등급과 부화할 종족은 UI에 표시하지 않는다. 개체값도 부화 전에는 확인할 수 없다.**
- 부화를 시작하면 표시되는 부화 시간을 통해 등급과 개체값을 대략 유추할 수 있다.
- 알은 인벤토리에 **수량형 아이템**으로 저장하고, 알 하나하나의 부화 결과 데이터는 별도 순서 목록에 저장한다.
- **알 획득 순간** 종족·개체값·성격 등 부화 데이터를 확정해 별도 저장한다. 부화 시작 시 대기열의 오래된 데이터부터 가져온다(FIFO).
- 알의 등장 종족 풀은 **획득 당시 해금 지역**에 따라 정해진다. 이후 다른 지역을 해금해도 기존 알의 부화 결과는 바뀌지 않는다.

## 확정 — 시간 계산
- 개체값이 31인 능력치 하나당 기본 부화 시간에 **50분 가산**. 6V면 +300분.
- 알 등급별 기본 시간에 개체값 추가 시간을 합한 다음 부화기 속도 강화 배율로 나눈다.
- 계산식: **최종 부화 시간 = (등급 기본 시간 + 50분 × V개수) / (1.1 ^ 속도강화레벨)**.
- 등급별 기본 시간은 미정.
- 부화 속도 강화는 레벨당 **×1.1 (곱연산)**, 최대 **Lv.30**.
- 부화 중 속도 강화를 하면 모든 진행 중인 알에 **즉시 적용**. 기존 진행도는 유지하고 남은 시간을 재계산한다.

## 확정 — 슬롯과 취소
- 초기 동시 부화 슬롯 **2개**, 최대 **18개**.
- 부화 슬롯 확장과 부화 속도 강화는 **각각 독립**.
- 부화 중인 알을 취소할 수 있으나 해당 **알 아이템·별도 데이터·투입 에너지가 모두 소멸**, 진행 시간도 초기화된다.
- 빈 슬롯은 앞 번호부터 사용한다.
- 자동 정렬: **부화 중인 알(부화 시작 순서) → 부화 완료된 알(부화 완료 순서) → 빈 슬롯**.
- 슬롯 번호가 이동해도 각 알의 부화 진행도는 그대로 유지된다.

## 확정 — 완료 수령
- 기본은 **수동 수령**. 수령하지 않은 완료 알은 슬롯을 차지한다.
- **개별 수령**과 **모두 수령** 버튼 제공.
- 모두 수령 시 보관함 공간이 허용하는 만큼 **부화 완료 순서대로** 수령하며, 못 받은 알은 완료 상태로 대기한다.

## 확정 — 자동화
- **자동 수령 1차:** 개체값 조건으로 선별.
- **자동 수령 2차:** 개체값 + 포켓몬 종족 조건.
- **자동 수령 3차 (최대):** 개체값 + 종족 + 성격 + 특성 조건.
- 자동 선별 조건에 **AND·OR 및 혼합 조건** 지원.
- 조건 충족 → 보관함 공간이 있으면 자동 수령. 공간이 부족하면 완료 상태로 대기하고 공간이 나면 자동 수령.
- 조건 미충족 → 포켓몬 자동 폐기, **별도 보상/에너지 환급 없음**, 슬롯 자동 해제.
- 별도 해금하는 **자동 부화 시작** 기능: ON/OFF 가능.
- ON이면 빈 슬롯을 앞에서부터 채우고, 대기 중인 알 데이터를 **FIFO**로 가져와 에너지를 소모해 부화 시작. 알이나 에너지가 부족하면 기다렸다가 충족 시 재개.
- 에너지 최소 보유량 예약 기능은 **사용하지 않는다**.

## 확정 — 포켓몬 보관함 및 방생
- 보관함 초기 **3마리**, 확장 후 최대 **151마리**.
- 보관함 강화에 따른 슬롯 증가량은 **강화 단계별로 달라지는 방식**이지만 수치와 비용은 나중에 결정한다.
- 원하는 포켓몬을 수동 방생할 수 있고 **별도 보상은 없다**.
- 지역 탐험 중인 포켓몬은 방생할 수 없다.
- 생활숙소 포켓몬의 영입·방생은 생산 능력치에 즉시 반영된다.

## 미확정
- 등급별 기본 부화 시간/에너지 비용/종족 배정.
- 부화기 슬롯 확장 및 부화 속도 강화의 비용, 해금 조건.
- 자동화 기능의 해금 조건·비용.
- 보관함 확장 단계별 증가량과 비용.
- 부화 진행 중인 알이 있는 상태에서 여러 자동화 규칙의 구체적인 예외 처리.
