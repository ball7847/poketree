# PokeTree 확정 기획 요약 · 최신 승인 내용 (2026-11-13)

> 기존 `/docs` 원본은 보존한다. 다음 대화는 [최신 개발 인수인계](handoff.md)를 우선 읽는다. 아래 최신 지역/전멸 규칙은 뒤쪽의 과거 원본 설명 중 충돌하는 내용보다 우선한다.

## 최근 확정된 지역 기획
| 지역 | 등장 레벨 | 주타입 | 해금 조건 |
|---|---|---|---|
| 바람의평원 | 1~6 | 노말/비행/벌레 | 최초 개방 |
| 미끌바위언덕 | 1~9 | 땅/바위/물 | 최초 개방 |
| 아삭사과숲 | 5~15 | 비행/벌레/풀 | 바람의평원 탐험 이동 50회 |
| 찌릿돌동굴 | 8~13 | 땅/바위/전기 | 미끌바위언덕 탐험 이동 80회 |
| 어둑시니숲 | 10~25 | 노말/악/고스트 | 아삭사과숲 탐험 이동 150회 |
| 깊은굴 | 12~26 | 땅/바위/강철 | 찌릿돌동굴 보스 최초 처치 |

- 혼합형 해금. 최초 2곳 개방, 나머지는 조건부 해금. 조건 달성 즉시 영구 개방.
- 이동 횟수는 **파티의 단일 탐험 단위**. 이동/걷기/채집/알 발견 등 비전투 탐험 행동당 +1, 전투 승리 종료 시 +1. 전투 개별 턴 0. 탐험 시작·정상 귀환·전멸 시 0.
- 전멸하면 탐험 종료. 기절 개체의 경험치/전리품 손실 후 남은 보관함 정산. **전멸 뒤 자동 회복·재시작 규칙은 폐기**.
- 지역별 출현 포켓몬/실제 레벨 분포/세부지역/행동 확률/보스/전리품은 미확정이며 임의 확정 금지.

## 전국도감 B-1 승인 범위 및 현재 구현
- 전체 종족 기본 데이터 + 폼·특성·진화 **원본 정보** 등록 승인. PokéAPI 고정 스냅샷 1,025종/1,351개 전투 변형/1,579개 원본 폼 항목 구축.
- 실제 특성 효과·진화 자동화·모든 기술·지역 출현은 **별도 승인 전까지 미구현**.
- 원작 데이터 우선순위 **포켓몬 챔피언스 > 9세대 > 8세대 > 7세대 …** 유지. 단, 전종 필드별 대조는 아직 완료되지 않았음. 출처 미검증 항목을 검증 완료로 표시 금지.

## 과거 기획 색인 (동일 주제 충돌 시 위의 최신 결정 우선)

# PokeTree 확정 기획 요약 · 개발용 색인

> 최종 기획의 기준은 기존 `/docs` 원본 문서다. 여기서는 게임 코드에 필요한 결정사항과 미확정 경계를 묶어 정리한다. 이 파일은 기존 문서를 삭제·이동하지 않는다.

## 게임의 중심
- 인간 없이 포켓몬만 존재하는 세계. 아르세우드 오염 복구라는 목표.
- 핵심은 무한 반복 전투·탐험, 보조는 포켓몬 성장/알/생활 생산.
- 지역 선택 → HP 100%인 포켓몬 1~3마리 선택 → 탐험 시작; 미리 저장한 파티 없음.
- 서로 다른 지역에서 동시 탐험 가능, 한 지역에는 한 탐험 그룹만 가능.
- 언제든 즉시 귀환 가능. 탐험 중 교체·방생은 불가.

## 지역과 세부 지역
- 지역마다 세부 지역 여러 개, 출발 지점 고정.
- 현재 세부 지역에서 행동 확률로 걷기/전투 조우/아이템·알 발견/이동 등을 정한다.
- 연결된 세부 지역만 이동하며 연결 방향(단방향·양방향) 및 목적지 이동 확률은 제작자가 지정한다.
- 세부 지역별로 적 마릿수 확률과 등장 가능 종족 목록을 설정한다.
- **모든 지역에 공통인 종족별 고유 출현 비중**을 기준으로 각 적의 종족을 독립 추첨한다. 동일 종족 중복 가능.
- 실제 비중/희귀도 구간/강화 공식은 미확정. 비중을 기준으로 희귀도를 분류하는 방향만 확정.

## 행동 타이머
- 탐험과 전투 모두 단일 행동 타이머 사용.
- 기본 3초, 1차 강화 2초, 2차 강화 1초. 가격/해금 조건은 미정.
- 탐험 행동 한 번, 전투 포켓몬 한 마리의 턴 한 번마다 타이머 1회 소비.

## 전투 라운드
- 1턴은 한 포켓몬의 행동 차례. 1라운드는 모든 포켓몬이 한 차례 행동할 기회를 갖는 주기(아군 3 + 적 3 = 최대 6턴).
- 아군/적군 통합 스피드 내림차순. 동속은 매 라운드 무작위.
- 먼저 기절한 포켓몬의 차례는 시간 소비 없이 생략.
- 부활은 즉시 생존 상태로 복귀하지만 행동은 다음 라운드부터.
- 평타 위력 10, 공격/특수공격 중 큰 능력치 사용(동률은 물리); 복합 타입 평타는 첫 타입부터 번갈아 적용.
- 액티브 기술 0~2개, PP 100 이상 기술 발동. PP 공식 세부 미정.
- 급소 기본 5%, 피해 1.5배. 능력치 랭크 ±6, 탐험 중 유지하며 비전투 턴마다 0 쪽으로 1단계 감소.
- 전투 승리 경험치는 전투 종료 시 생존자만 균등 분배 후 각각 올림.
- 기절 시 해당 레벨의 누적 경험치 0, 레벨은 유지.
- **피해량·명중·기술 세부 데이터가 미확정이므로 웹 프로토타입은 시연용 피해량을 사용**한다.

## 무한 탐험·보스·해금
- 무한 탐험 중 지역별 도전 조건 충족 시 보스 자동 조우.
- 보스 승패 후 일반 탐험으로 복귀하고 조건 초기화; 재등장 여부 지역별 설정.
- 보스 처치만으로 지역 자동 이동·해금하지 않음. 해금 조건은 각 지역별 AND/OR 조합.
- 잠긴 지역은 전체 공개/진행도 숨김/지역 자체 숨김 중 지역마다 선택.
- 해금 시 알림을 띄우되 현재 화면과 기존 탐험은 그대로 유지.

## HP·전리품
- 탐험 시작 시 전원 HP 100%. 다음 전투까지 남은 HP 유지, 탐험 중 자연 회복 없음.
- 전멸하면 전체 HP 100%까지 회복한 뒤 같은 지역에서 자동 재개.
- 귀환한 포켓몬은 자연 회복하며 HP가 낮아도 생활 활동 가능.
- 아이템은 탐험 참가 포켓몬 개별 보관함에 랜덤 분배(기절 개체도 가능).
- 개별 보관함 기본 100칸, 강화당 +100, 최대 2,000칸. 1아이템 1칸, 스택 없음.
- 기절 시마다 floor(보유 아이템/2)개 무작위 손실.
- 전리품은 귀환 시 획득, 보스 보상도 손실 대상.

## 알림
- 지역 해금, 보스 처치, 부화 등 주요 이벤트만 기록.
- 최근 30개 순환 보관, 전체 삭제만 가능, 종료 후 재실행 시 초기화.
- 짧은 알림 표시, 화면 자동 전환 없음. 동시 알림 처리 방식 미정.

## 아직 개발 시 임의 확정하면 안 되는 것
- 정확한 지역·세부 지역·적 목록 및 확률, 종족별 출현 비중/희귀도 구간.
- 실제 전투 피해량·명중·기술·PP 정식 공식, 회복 속도, 적/아군 스탯.
- 지역별 보스와 해금 조건, 드롭, 알/생활/경제 세부 수치.
- 전투숙소·생활숙소 분리 여부(미확정).
