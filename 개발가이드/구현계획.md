## 1차 — 브라우저 실행형 탐험/전투 프로토타입
- 확정 규칙의 최소 루프를 재현하고 데모 수치는 `게임/data.js`에 격리한다.
- 지역을 선택하고 포켓몬 1~3마리를 출발시킨다.
- 고정 시작점에서 확률적으로 이동·조우·발견 이벤트를 진행한다.
- 조우 마릿수와 종족을 각각 추첨하며 동일 종족 중복을 허용한다.
- 3초 타이머로 탐험과 전투의 개별 행동을 공통 처리한다.
- 스피드 순서로 1마리씩 행동하며 매 라운드 동률을 재추첨한다.
- 시연용 전투 피해와 HP, 회복은 실제 데이터로 교체 전까지 **임시값**이다.


## 부분 갱신 동작 검증
- [ ] 100ms 카운트다운 진행 동안 HP 카드, 보관함, 로그 DOM이 재생성되지 않는다.
- [ ] 새 탐험 로그 한 개가 생성될 때 기존 로그 노드와 스크롤 상태가 유지된다.
- [ ] 전투 피해 발생 시 해당 포켓몬의 HP 표현만 변화하고 다른 개체 카드는 그대로 남는다.
- [ ] 적군 등장/기절/전투 종료 시 새로 추가되거나 제거되는 카드에 한정해 DOM 변경.
- [ ] 전리품 획득·기절 손실·귀환 시에만 보관함 내용 반영.
- [ ] 체크박스 선택이 무관한 게임 상태 변화로 사라지지 않는다.
- [ ] 로그/알림 개수 상한에서 가장 오래된 한 행만 제거.
- [ ] 지역 이동·전투 진행 후 페이지 전체 새로고침 없이 동일 URL·문서 유지.
- [ ] 브라우저 개발자 도구 Performance/Elements로 과도한 DOM 재생성 여부 확인.

## 지역 목록 → 탐험 상세창 UI 개편 (2026-11-12)

### 승인된 구현 범위
- 탐험 탭 메인은 **세로 스크롤 가능한 지역 카드 목록**. 카드 전체를 눌러 그 지역의 상세창을 연다.
- 카드에 지역명, 파견 포켓몬, 상태·최근 탐험 행동, 행동 진행률, 전리품 개수를 표시한다.
- 상세창에는 지역/현재 세부 지역, 탐험·전투 포켓몬, 행동 로그, 진행률, 출발/후퇴/닫기를 표시한다.
- 대기 지역의 상세창에서 **HP 100%인 포켓몬 1~3마리 선택 → 출발**.
- 진행 지역은 상세창을 닫더라도 계속 탐험한다. 후퇴 버튼은 해당 지역의 포켓몬만 즉시 귀환시킨다.
- 실제 이미지가 아직 없으므로 **시연용 CSS 배경·텍스트 아바타**로 대체한다. 해당 배경·아이콘은 최종 디자인으로 확정하지 않는다.
- **팝업 최종 형태는 미확정**. 지금은 임시 `<dialog>`를 사용하며 이후 교체 가능.
- 모달 내부 전투 배치/HP 표시 역시 시연용 UI이며 최종 디자인 미확정.

### 실제 코드 구조
| 경로 | 역할 |
|---|---|
| `게임/data.js` | 시연용 종족별 전역 가중치, 지역·세부 지역·시연 포켓몬. **바람의 들판 + 시연용 초원은 확정 맵 아님** |
| `게임/engine/core.js` | 전역 포켓몬 목록, **지역 ID별 탐험 상태**, 상태 변경 알림, 기록 데이터 |
| `게임/engine/combat.js` | 지역별 적 조우, 스피드/라운드/턴·기절 처리; 임시 피해량 |
| `게임/engine/exploration.js` | 지역별 출발/후퇴, 세부 지역 행동 확률, 전리품, 회복, 독립 시간 누적 |
| `게임/ui/navigation.js` | 기존 4탭과 각 탭 스크롤 유지, 팝업 열고 닫기 |
| `게임/ui/exploration-list.js` | 지역 카드 생성 및 **변경 내용만 DOM 갱신** |
| `게임/ui/exploration-detail.js` | 카드 선택 시 상세창, 포켓몬 선택, 후퇴/닫기, 상태별 내용 갱신 |
| `게임/game.js` | 화면 초기화, 로그/알림·포켓몬 보관 목록, 100ms 진행 타이머 연결 |

### 다중 탐험 시계
- **업그레이드된 행동 간격(3초/2초/1초)은 전 지역 공통**.
- **각 탐험 지역은 자신의 행동 카운트다운을 별도로 유지**하고 동시에 진행.
- **한 지역의 탐험과 전투는 해당 지역의 같은 카운트다운을 사용**. 전투 중 한 포켓몬의 턴마다 한 번 소모.
- 탐험 중인 포켓몬은 다른 지역으로 중복 파견할 수 없음.
- 같은 지역의 탐험을 중복 시작할 수 없음.
- 탐험 중 전원 기절하면 임시 회복 속도로 전원 회복 후 동일 세부 지역에서 자동 재개.

### 회귀 테스트 체크리스트 (실제 브라우저 수동 검증 필요)
- [ ] 첫 화면에서 탐험 탭 진입 → 지역 카드 2개 표시.
- [ ] 지역 카드 선택 → 상세창에서 포켓몬 선택 → 시작.
- [ ] 두 지역에 각각 1마리 이상 배치하여 **동시 탐험** 확인.
- [ ] 이미 파견된 포켓몬이 다른 지역의 선택에서 제외되는지 확인.
- [ ] 상세창 닫기 → 다른 탭 → 복귀해도 탐험 유지.
- [ ] 탭 전환 및 카드 상태 갱신 중 지역 목록의 스크롤 위치 유지.
- [ ] 상세창을 연 상태에서 세부 지역 이동·전투·회복 시 적절한 값만 갱신.
- [ ] 후퇴 시 해당 지역만 종료하고 타 지역은 계속 진행.
- [ ] 3초→2초→1초 테스트 설정을 두 지역에 공통 적용.
- [ ] 휴대폰 화면에서 가로 스크롤 없음; PC 최대 1400px.
- [ ] 알림/설정/기록과 기존 상단·하단 공통 UI 정상 동작.

### 미확정·미구현
- 실제 지역 목록 및 개별 지도 이미지·포켓몬 스프라이트, 카드 우측 아이콘 사양.
- 보스 도전·해금 조건, 실제 탐험 보상, 전투 공식 및 PP/기술·경험치.
- 정식 저장·재접속, 세션 외 오프라인 진행, 동시 실행 브라우저 간 동기화.
- 실제 포켓몬·지역 수치, 회복 속도·경제 자원.
- 팝업 최종 표시 형식과 전투 화면의 최종 배치.

## 2차 — 규칙 확정 후 본구현
- 정식 피해량·명중·스킬 데이터/PP 공식
- 종족/지역/연결/보스/해금 실데이터와 보스별 조건
- 알 획득/부화, 포켓몬 보관함 및 성장/진화
- 플레이어 전리품 창고, 경제·생활 생산과 자동 배치
- 오프라인 진행/저장·복원 정책, 운영 UI, 테스트 자동화

## 확인할 항목
1. 턴당 1회의 시계 소비; 6명 생존 시 기본 18초/라운드.
2. 적이 기절하면 남은 차례가 시간 소모 없이 생략.
3. 동속은 매 라운드 무작위; 다음 라운드에서 새 순서.
4. 동일 종족 중복 조우 허용.
5. 전역 종족 비중은 위치별로 변하지 않지만 실제 확률은 등장 목록 합계로 달라짐.
6. 보관함은 포켓몬당 100~2000칸; 아이템 1개당 1칸; 기절 시 floor(개수/2) 무작위 손실.
7. 30개까지만 기록하고 전체 삭제·세션 종료 초기화되는 알림 로그(정식 알림 UI는 후속 연결).

## 의도적으로 임시인 항목
- 예시 지역과 포켓몬 이름/비중, 전투 피해량, 개체 HP·속도, 회복 속도, 보상 아이템 종류, 파티용 시연 개체.
- 미확정 공식·비용·해금 조건·실제 지역 목록은 임의로 최종 확정하지 않는다.
